🏎️ Retro Neon Racer
A fast-paced, highly responsive 2D top-down endless car racing game built from scratch using clean, object-oriented vanilla JavaScript and the HTML5 Canvas API. No external dependencies, frameworks, or asset files required.

🕹️ Live Demo & Gameplay
The game features an adaptive, neon-infused retro arcade aesthetic. Avoid oncoming traffic, survive as long as you can, and manage your Nitro carefully to maximize your score.

✨ Features Included
Lane-Based System: Clean horizontal movement tracking across 4 highway lanes.

Procedural Infinite Scrolling: A continuous canvas matrix mapping architecture mimics high-speed motion without memory degradation.

Dynamic Difficulty Scaling: Obstacle spawn rates and base scroll speeds steadily scale upward the longer you survive.

Nitro Boost Engine: Hold to double game speed mechanics and gain a 2x score multiplier at the risk of faster reaction requirements.

Sound Synthesizer Engine: Uses the modern browser Web Audio API to generate native arcade sounds (crashes, scoring beeps) completely programmatically without loading .mp3 or .wav files.

High Score Tracking: Connects instantly with local storage (localStorage) to preserve individual player personal records across browser sessions.

Fully Responsive & Mobile Optimized: Detects viewport boundaries seamlessly with automatic touch controller button integration for mobile gaming profiles.

🚀 Quick Start Setup
Clone or download the source code files (index.html, style.css, script.js).

Keep all three files together inside the same folder directory.

Open index.html inside any modern web browser (Chrome, Firefox, Safari, Edge). No local server installation or compilers required!
